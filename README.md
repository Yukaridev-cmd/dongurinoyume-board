# どんぐりの夢 共有ボード

ハンドメイド活動「どんぐりの夢」（あみぐるみ等の展示・販売）の共有ページ。作品・在庫、イベント、ポップ、ブースの工夫をまとめたスマホ向けの1ページ構成で、GitHub Pagesで公開する。

## 構成

- `index.html`：ページ本体（ホーム／イベント／作品・在庫／ブース／ポップ置き場／LINE用文面の6ビューを切り替える単一ファイル）
- `assets/`：写真とポップの画像
- `icon.webp`：アイコン
- `comments-config.js` / `comments-api.js`：LINE内のコメント共有接続
- `backend/`：非公開DBへ接続するWorkerのコードと設定例
- `docs/comments-setup.md`：共有設定・配備前の確認手順

## 編集の進め方

- 編集は人でもAI（Claude Code、Codex、ChatGPT等）でも同じ手順で行う。`index.html` と `assets/` を直接編集し、`main` ブランチへプッシュすると、数分で GitHub Pages へ自動反映される
- 作品・イベント・ポップの内容の正本は、別に運用している更新シート（Googleスプレッドシート）側の記入内容とする。シートで変更された内容をこのページへ反映する運用

## 編集ルール

- 文面は言い切り形にする。丁寧語（です・ます）と「だ」「である」で終わる文は使わない
- 文面は本人・妻の行動（やること・したこと）で書く。AIの所感は書かない
- イベント名は末尾に開催年月を「（YYYY年M月）」の形で付ける
- 価格・日程・場所は確認できたものだけを書く。未確認のものは「未確認」と明記し、推測で埋めない
- 終わったイベントは新しい順に並べる
- 画像は長辺1080px・JPEG品質80を目安に圧縮してから `assets/` へ追加する
- 作品の写真は実物写真と本人のポップ原画を使う。生成イラストは使わない（ポップのイラスト版として作成済みのものは除く）
- ページ全体の背景はクリーム色（#fdf6e0）で固定し、フォントは Meiryo UI を基本とする

## コメント共有

コメントはLINEで本人確認した二人だけで共有する。保存先とLIFFの設定が空の場合は投稿・取得を止め、画面に設定待ちを表示する。公開ページに実際のコメント、LINEユーザーID、秘密設定を追加しない。接続設定と確認状況は [コメント共有の設定手順](docs/comments-setup.md) を参照する。

ローカル検証は Node.js 24.13以降で `npm ci`、`npm test`、`npm run check` を実行する。テスト用の識別子とコメントは架空の値だけを使う。
