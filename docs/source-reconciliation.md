# 更新シートと公開ページの照合

2026年11月16日に更新シートの構成と作品・在庫の記入内容を確認。元のシートと写真を変更せず、公開情報と確認待ちの差分を分けて保全する。

| 項目 | 確認できた差分 | 対応 |
| --- | --- | --- |
| 作品一覧 | シート27作品に対して公開ページ26作品 | 欠けていた「ハートを持つくまのあみぐるみ」を追加。価格・写真・在庫は未確認のまま |
| 在庫数・状態・現品限り | シートの各欄は未入力 | 写真点数や空欄から実在庫・売切れを推定しない。棚卸メモを別に保存し、正本への反映は確認後 |
| くまモチーフの巾着 | シートの写真点数メモと公開画像の説明に差 | 既存画像・説明を残し、別撮影の可能性も含めて照合待ち。写真の点数を在庫に使わない |
| ハッピーパック | 登録画像はポップ | ポップ画像と実物写真を区別する注記を追加。実物写真と中身は確認待ち |
| 大きいあみぐるみ | 対応する本体写真なし | 元の価格表由来の記載を保全し、実物写真は確認待ちと表示 |
| 工夫・やりたいこと | シートは見出しのみ。公開ページには既存の工夫4項目・アイデア4項目・やること5項目 | 公開ページの既存内容を削除せず、正本へも自動転記しない。今後の私的な記録は二人用の別領域へ |
| ハートまつり（2026年11月） | 日付の記載と備考に不整合 | 公開ページの2026年11月15日を保全。元シートの備考修正は確認待ち |
| クリスマスマルシェ | 場所の記載に前年由来の情報を含む | 今年の確定情報として追加・変更しない。開催場所の再確認待ち |

全27作品の対応表は `catalog.json` に生成する。登録済みの作品名・写真パス・写真説明だけを含め、在庫実数・売上・私的な記録は含めない。`npm run catalog` で画像ファイルの存在と対応を再確認する。写真の内容と商品名が完全に一致するか、色違い・別撮影をどう区別するかは本人と妻の現物確認を残す。

新しい「棚卸メモ」は更新シートを置き換えない。現物を数えた内容と確認の根拠を残し、「更新依頼にする」で反映する内容をまとめる。コメントや売上を含む依頼は公開ページへそのまま掲載せず、本人が送信先と内容を確認してからコピーする。
