# 元画素を保つ背景調整

作品そのものを生成し直さない。作品の色・顔・編み目・輪郭と、その周囲の余裕を元写真の画素で保持し、外側の背景だけを淡い生成りに合成する。展示風景・会場写真は加工しない。元写真を上書きせず、派生画像は別名のPNGとして保存する。

現在の背景加工の採用は0枚。鳥のソフトクリームとニャカロンの試作2枚は、輪郭外に残した元の影が浮いて見えるため非採用に変更し、ボードの表示を元写真へ戻した。原本・コメント対象ID・旧派生画像・マスクは保持している。`artwork/photo-backgrounds.json` の `status: rejected` は制作履歴であり、再採用の承認を示さない。

旧試作は輪郭の外に20pxの保護幅を設け、保護領域198,728画素・444,544画素の一致を確認したが、数値上の画素保持だけでは自然な影を保証できなかった。画像編集ツールでの再試作も、編み目や輪郭が変わったため非採用。作品の形・顔・編み目・輪郭・色を保ち、自然な背景との両方を目視確認できるものだけ今後採用する。品質を満たさない場合は元写真を維持し、完了扱いにしない。

`artwork/photo-backgrounds.json` は元写真・派生画像・マスクのパス、原本SHA256、確認済みの輪郭、保護画素の数とハッシュを持つ。`scripts/photo-backgrounds.py` がマスクと合成を再現し、原本の不変、保護領域の一致、合成結果、マスクを検証する。背景マスクの選択が適切かは数値検証だけでは確定できないため、原本との目視比較も必須。

```powershell
# 任意の画像制作ツール。Python・Pillow・NumPyを使う。アプリの実行には不要。
python scripts/photo-backgrounds.py

# 確認済みの輪郭から派生画像とマスクだけを再作成。原本JPEGは書き換えない。
python scripts/photo-backgrounds.py --write
```

写真カードの `data-comment-key` と `gallery.json` の `id`・`src` は変更しない。`displaySrc` は表示用の派生画像だけを指定する。「元写真」は共通の拡大ダイアログで表示し、画面遷移やコメント欄の再生成を行わない。新しい加工対象を採用する場合も、同じ保全・目視比較・画素検証・公開ファイル確認を行う。包装の反射、細い金具、毛羽立ち、手との重なり、元から付いた文字を安全に分離できないものは元写真のまま保持する。
