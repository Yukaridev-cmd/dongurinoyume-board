# 機能の振り分け

利用ログから頻度を断定せず、本人が挙げた使い方を基準に整理する。目的は夫婦の記録・相談・準備をLINEから短い手順で行うこと。画面の入口を減らす変更と、保存済みデータを消す変更を分ける。

| 機能 | 振り分け | 根拠と今回の扱い |
| --- | --- | --- |
| 振り返り・売上・費用 | 必須 | 同じ出店の記録として1画面にまとめたまま維持。未入力と0円を区別 |
| やりたいこと・期限・完了 | 必須 | 二人の次の行動を管理する用途。追加・完了の短い操作を維持 |
| 棚卸メモ | 必須 | 実数を確認して残す用途。写真点数から推定せず、正本シートの自動上書きもしない |
| 作品写真・価格を見る | 必須 | 作るもの・売るものを確認する入口。ホームと記録画面から作品一覧へ直接進む |
| コメント | 必須 | 相手への相談・連絡用。作品やイベントごとの文脈を維持 |
| AI更新依頼 | 必須 | ボードをどう変えるかを整理して渡す用途。コメントとは別に未対応状態を管理し、必要なコメントから依頼へ移せる |
| 写真と作品の照合 | 棚卸の補助へ | 普段の写真閲覧とは別の確認作業。独立した主要タブを外し、棚卸から1回で開く。既存の照合記録と編集機能は維持 |
| 件数・期限の近い作業 | 二次導線 | 一覧の検索・未完了条件と重なる補助表示。折りたたみ内に残す |
| 検索・未完了条件・並べ替え | 一覧内に維持 | 記録が増えても対象に到達するための機能。独立メニューにはしない |
| 保存説明・JSON書き出し | 二次導線 | 毎回の入力には不要だが、下書きの扱い確認と手元保管に必要。補助メニューへまとめる |
| イベント予定・記録 | 資料として維持 | 出店準備の根拠。ボードのイベントタブから開く |
| ブースの工夫・ポップ | 資料として維持 | 制作・印刷・展示に必要な既存資産。内容や画像を削除しない |
| LINE用文面 | 不要候補・当面維持 | 日常コメントと用途が重なる部分があるが、既存の連絡テンプレートを使っていないとは断定できない。削除は保留 |
| 全コメントのコピー・ファイル保存 | 統合候補・当面維持 | AI向けの変更依頼は専用機能へ整理済み。相手へまとめて連絡する用途もあるため、既存コメントと機能を残す |
| 公開資料内の固定やること | 統合候補・保全 | 私的な作業管理と重なるが、元シートと出所が異なる。自動移行・削除・進捗の推測は行わない |
| 記録画面下部の重複ナビ | 整理済み | 同じ画面内にある種類選択・作品ボードへの戻りと重複。入口だけを削除し、機能とデータは維持 |
| キャッチコピー・大きな紹介画像 | 前回整理済み | 日々の操作に不要という本人の指摘に合わせて除去 |

## アイコンの意味

独自の24×24線画SVGを使用する。線幅・角丸・色を共通にし、文字と併記する。外部画像・アイコンフォント・追加ライブラリは使わない。装飾SVGは読み上げ対象から外し、ボタン名は文字で伝える。

| 図 | 用途 |
| --- | --- |
| 帳面 | 振り返り・売上 |
| チェック付きリスト | やりたいこと |
| 箱 | 棚卸メモ |
| 作品を入れるバッグ | 作品一覧・作品写真 |
| 吹き出し | コメント |
| 外へ向かう矢印付き書類 | 更新依頼 |
| 写真枠 | 写真と作品の照合 |
| カレンダー・売場・看板 | イベント・ブース・ポップ |

写真照合の記録、既存コメント、売上、作業、履歴は削除しない。外部AIへの自動送信も追加しない。不要候補は実際の利用を確認してから判断する。

## 今回の検証

- 320px幅の記録画面で6つのタブが3列×2段、各高さ約44px。横スクロールなし。文字を残して図を横に配置。
- 390px幅のホームで主要操作が2列×3段、各高さ70px。テスト環境の案内を含め最後の段の下端は約465px。アイコン追加で段数は増えない。
- 作品写真はホームから1操作、写真照合は棚卸から1操作。照合画面でも棚卸タブを選択状態に保ち、棚卸への戻りも1操作。
- 作品概要の古い26件表示を、表示中の27作品・価格未確認8作品へ修正。作品カードと概要の整合を自動検証。
- アイコンの文字ラベル維持、読み上げ対象除外、重複挿入防止、外部画像なしを自動検証。認証・下書き保護の既存回帰テストも維持。
- 本人限定テストへ配備し、10配信ファイルの一致と匿名・偽造アクセスの拒否17項目を確認。本番の未設定時拒否9項目も確認。DBの記録件数・版合計・履歴件数・コメント件数・版合計は更新前後で一致。

今回の表示変更後のスマホLINE実機操作は未確認。ブラウザーの幅指定とローカルの架空データで検証し、二人での利用は奥様の登録後に確認する。
