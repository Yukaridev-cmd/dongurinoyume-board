# スマホの短い操作導線

## 画面の構成

ホームのキャッチコピー・大きな写真・紹介文を外し、振り返り・売上、やりたいこと、棚卸メモ、AI更新依頼、コメント、写真確認を同じ大きさの6ボタンに揃える。スマホでは2列3行。既存の出店予定・資料・コメント一覧は折りたたみ内に保全し、上部の作品・イベント等のメニューから直接開ける。

二人の記録は一覧を先に表示する。種類の選択は3列2行、新規追加は見出しの右。新規追加・編集・記録からの依頼作成を選んだときだけ入力欄を開き、一覧を隠す。保存すると一覧へ戻る。未保存で戻る・種類を切り替える場合は取消確認を通す。背景移行では入力を保護し、同じ利用者を確認した場合だけ入力画面ごと復元する。

件数、期限の近い作業、保存説明、ファイル書き出しは補助メニューへまとめる。AI依頼の確認・コピーは依頼一覧の上部に置き、他の種類では表示しない。140文字を超える本文は一覧で折りたたみ、全文を開ける。テスト環境の注意書きも1行から展開する形にまとめる。

## 主要な使い方

文字入力・認証待ちを除くボタン操作数。記録が読み込める状態を前提に、ホームから数える。

| 目的 | 操作 | 入力開始まで／保存まで |
| --- | --- | --- |
| 振り返り・売上を残す | 振り返り・売上 → 記録を追加 → 入力 → 保存 | 2回／3回 |
| やりたいことを残す | やりたいこと → 記録を追加 → 入力 → 保存 | 2回／3回 |
| 棚卸結果を残す | 棚卸メモ → 記録を追加 → 数を入力 → 保存 | 2回／3回 |
| 連絡・相談を書く | コメントを書く → 入力 → 追加 | 1回／2回 |
| AIへ既存の依頼を渡す | AI更新依頼 → 送る内容を確認 → コピー | コピーまで3回 |
| 作業を完了にする | やりたいこと → 対象の「完了にする」 | 2回 |

AIへの貼り付け・送信は利用者が送信先と内容を確認して行う。自動送信なし。大量の記録から対象を探す場合は検索・未完了条件・並べ替えを使う。

## スマホ幅での検証

ローカルChromeの合成データ画面で確認した。実LINEのソフトウェアキーボードや、全端末で同じ寸法になることの保証とは区別する。

- 390×844設定のホーム：入口6個の上端は206／284／362px、高さ70px。2列の幅と行位置が一致し、最後の入口の下端432pxまで最初の画面内に表示。スクロール不要
- コメント：ホームから1回でパネルを開き、入力欄は画面内の516〜648pxに表示
- 記録一覧：320×760設定で一覧上端451px。種類ボタン6個は88×44pxで3列2行に整列。ページ幅とスクロール幅はいずれも305pxで横方向のはみ出しなし
- AI依頼：コピーの上端447px。依頼一覧の末尾までスクロールせず操作可能
- 振り返りの0円と費用空欄、作業の追加・完了、棚卸0点、棚卸から更新依頼作成、依頼の確認・コピーを実ブラウザーで実行。すべてPC内の合成データのみ
- 保存・権限・認証失効・下書き復元等の既存検査を含む59件の自動テストが成功。入力画面の開閉、取消拒否、背景移行から入力画面の復元、種類別の依頼操作表示を追加確認

記録が増えた場合や長い入力の全文を開いた場合にはスクロールが生じる。追加画面では他の記録を隠し、入力と保存に集中できる構成。既存画像・価格・イベント情報の比較検査も継続する。
