# 作品と出店写真の整理

作品・在庫は「作品／個人依頼／贈り物／個人作品」の4分類を一回の操作で切り替える。個人作品は右端に配置。上部検索は分類をまたいで公開の名前・説明を検索し、入力中は「全分類の検索結果」と表示。分類を押した場合はその分類で絞り込む。コメント本文は検索に使わず、分類切替で入力欄を再生成・初期化しない。

作品名は既存の「にゃんバーガー」「ウォンバットのあみぐるみ」等の命名を参考にする。本人の名称がないものは写真の見た目を短く記述し、「仮の呼び名」を明記。別の販売作品と同じ個体だと推定して在庫・価格・記録を統合しない。

## コメントと保全

旧版の固定対象213件を削除せず、写真のノードとIDを移動する。旧写真一覧全体の対象も出店・作品の全体コメントとして保持。全213対象の保存と対象外拒否、元の固定対象集合の包含をテストする。移動した記録に私的なコメント本文を埋め込まない。

出店一覧は代表写真と短い概要を持つカード。PCは2列、スマホは1列で閉じたカードの高さを揃える。長い名前は2行に収め、詳細画面の見出しで全文を読める。入力欄・エラー・認証後のコメントが開いた場合は内容に応じて伸ばし、切り捨てない。写真全体は「開く」から一回で進む詳細画面に折りたたまず初期表示する。公開写真だけの詳細画面は `data-public-photo-record` で区別し、未登録の非公開出店IDへ保存させない。既存の写真・公開範囲・元の作品27件・非公開の保存設定を変更しない。
